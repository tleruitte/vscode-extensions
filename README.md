# VS Code extensions

My extensions for VS Code and Cursor, one folder each, published to the [Open VSX Registry](https://open-vsx.org/namespace/tleruitte).

| Extension | What it does |
| --- | --- |
| [Open on GitHub](open-on-github) | Opens the current file and line on GitHub in the repository default branch. |

To build, package, or publish an extension, see [CONTRIBUTING.md](CONTRIBUTING.md).
